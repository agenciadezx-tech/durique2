# Durique

Agenda, pacientes e turmas para clínicas de fisioterapia e estúdios de pilates.

## Rodar localmente

```bash
cp .env.example .env.local   # preencha com a URL e a chave pública do Supabase
npm install
npm run dev
```

Abra http://localhost:3000.

## Banco de dados

As migrações ficam em `supabase/migrations/`. Veja `CLAUDE.md` para as regras do projeto.
